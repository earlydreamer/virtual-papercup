# 가상 종이컵

휴대폰의 움직임에 따라 컵 안의 물이 출렁이는 웹 앱입니다. 이니셜 D의 두부배달 장면처럼, 물을 흘리지 않고 부드럽게 움직이는 감각을 연습할 수 있습니다.

컵이 기울면 물이 넘치고, 넘친 만큼 물이 줄어듭니다. 넘칠 때는 알림음과 진동으로 알려주며, 끝나면 넘친 횟수와 경과 시간, 최대 기울기, 흘린 양을 볼 수 있습니다.

## 사용 방법

1. 휴대폰을 흔들리지 않게 고정하고 물 높이를 정합니다. 물이 많을수록 쉽게 넘칩니다.
2. 움직임이 없는 상태에서 **기준 잡기**를 누릅니다. 센서 권한을 요청하면 허용합니다.
3. 1.5초 동안 자세를 유지한 뒤 **시작**을 누릅니다.
4. 움직임에 따라 물이 출렁입니다. **종료**를 누르거나 물이 거의 소진되면 결과가 표시됩니다.

휴대폰을 다시 놓거나 고정한 각도가 바뀌면 기준을 다시 잡으세요.

준비 화면에서 **물 높이 유지**를 켜면 물이 줄지 않아 **종료**를 누를 때까지 측정할 수 있습니다. 넘칠 때마다 알림이 울리고, 결과에는 넘친 양을 컵 단위로 합산해 표시합니다.

센서가 없는 PC나 센서 권한을 거부한 환경에서는 마우스와 방향키로 체험할 수 있습니다. 시작한 뒤 컵 위에서 마우스를 움직이거나 방향키를 누르세요. 스페이스 키는 기울기를 가운데로 돌립니다.

## 실행하기

이 저장소에는 웹 앱 소스가 들어 있습니다. 직접 실행하려면 Node.js 24와 npm을 설치한 뒤 프로젝트 폴더에서 다음 명령을 실행합니다.

```text
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저로 엽니다. 개발용 HTTPS 인증서를 사용하므로 브라우저에 인증서 경고가 나타날 수 있습니다. 휴대폰에서 확인할 때 필요한 설정은 [개발 안내](docs/DEVELOPMENT.md)에 있습니다.

## 기록

측정 결과는 열린 페이지 안에서만 유지됩니다. 새로고침하거나 페이지를 닫으면 사라지며, 서버로 전송하지 않습니다.

개발에 참여하려면 [개발 규칙](docs/CONVENTIONS.md)을 확인하세요. 구현에 관한 설명은 [기술 문서](docs/TECHNICAL.md)에 있습니다.
