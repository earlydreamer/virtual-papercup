# 가상 종이컵

휴대폰의 움직임에 따라 컵 안의 물이 출렁이는 웹 앱입니다. 이니셜 D의 두부배달 장면처럼, 물을 흘리지 않고 부드럽게 움직이는 감각을 연습할 수 있습니다.

컵이 기울면 물이 넘치고, 넘친 만큼 물이 줄어듭니다. 넘칠 때는 알림음과 진동으로 알려주며, 끝나면 넘친 횟수와 경과 시간, 최대 기울기, 흘린 양을 볼 수 있습니다.

**설정 → 그래픽 모드**에서 입체 종이컵을 보여주는 3D와 기존 단면을 보여주는 2D를 선택할 수 있습니다. 3D에서는 컵을 고정한 채 앞뒤·좌우 기울기에 따라 수면이 출렁이고, 넘치는 테두리에서 물이 흘러내립니다. 한 손가락이나 마우스 왼쪽 버튼으로 화면을 드래그하면 컵 주위를 둘러볼 수 있습니다. 손을 떼면 시점이 멈추며, **설정 → 시점 초기화**로 처음 구도로 돌아갑니다. 화면을 바꿔도 측정 기록은 이어집니다. 3D를 사용할 수 없는 환경에서는 2D로 표시합니다.

## 사용 방법

1. **설정 → 다음 측정의 물**에서 시작 물 높이를 정하고, 휴대폰을 흔들리지 않게 고정합니다. 물이 많을수록 쉽게 넘칩니다.
2. 움직임이 없는 상태에서 **기준 잡기**를 누릅니다. 센서 권한을 요청하면 허용합니다.
3. 1.5초 동안 자세를 유지한 뒤 **시작**을 누릅니다.
4. 움직임에 따라 물이 출렁입니다. **종료**를 누르거나 물이 거의 소진되면 결과가 표시됩니다.

휴대폰을 다시 놓거나 고정한 각도가 바뀌면 기준을 다시 잡으세요.

**설정 → 물 높이 유지**를 켠 뒤 시작하면 물이 줄지 않아 **종료**를 누를 때까지 측정할 수 있습니다. 넘칠 때마다 알림이 울리고, 결과에는 넘친 양을 컵 단위로 합산해 표시합니다.

센서가 없는 PC나 센서 권한을 거부한 환경에서는 시작한 뒤 방향키로 물을 기울일 수 있습니다. 스페이스 키는 기울기를 가운데로 돌립니다. 2D 모드에서는 컵 위에서 마우스를 움직여도 물이 반응합니다. 3D 모드의 터치·마우스 드래그는 시점만 바꿉니다.

## 설정

왼쪽 위 **설정**을 누르면 옵션을 한곳에서 바꿀 수 있습니다. 측정 중에 열면 시간과 물의 움직임이 잠시 멈추고, 닫으면 이어집니다. **완료** 또는 **닫고 계속하기**, 닫기 버튼, Esc 키로 닫을 수 있습니다.

| 분류 | 선택할 수 있는 옵션 |
| --- | --- |
| 화면 | 2D·3D 모드, 3D 선명도 3단계, 기울기 게이지 표시 |
| 시점 | 드래그 회전 잠금, 방향 버튼으로 회전, 시점 초기화 |
| 다음 측정의 물 | 시작 높이 30~92%, 물 높이 유지 |
| 알림 | 소리 켜기·끄기와 미리 듣기, 지원 브라우저에서 진동 켜기·끄기 |

물 설정은 다음 시작에 적용됩니다. 측정 중인 컵의 높이도 바꾸려면 **현재 컵에도 이 높이 적용**을 누릅니다. 이때 넘침 기록은 이어집니다. 준비 화면과 화면 아래의 **물 설정** 버튼으로 물 옵션에 바로 갈 수 있습니다.

선택값은 같은 브라우저에 자동 저장됩니다. **화면·알림 기본값 복원**은 그래픽, 시점 고정, 게이지와 알림을 기본값으로 돌리고 시점을 초기화합니다. 물 설정과 측정 기록은 유지합니다. 저장소를 사용할 수 없는 환경에서는 현재 페이지에만 적용되며 설정 패널에 안내합니다.

## 실행하기

이 저장소에는 웹 앱 소스가 들어 있습니다. 직접 실행하려면 Node.js 24와 npm을 설치한 뒤 프로젝트 폴더에서 다음 명령을 실행합니다.

```text
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저로 엽니다. 개발용 HTTPS 인증서를 사용하므로 브라우저에 인증서 경고가 나타날 수 있습니다. 휴대폰에서 확인할 때 필요한 설정은 [개발 안내](docs/DEVELOPMENT.md)에 있습니다.

## 기록

측정 결과는 열린 페이지 안에서만 유지됩니다. 새로고침하거나 페이지를 닫으면 사라지며, 서버로 전송하지 않습니다.

개발에 참여하려면 [개발 규칙](docs/CONVENTIONS.md)을 확인하세요. 구현에 관한 설명은 [기술 문서](docs/TECHNICAL.md)에 있습니다.
