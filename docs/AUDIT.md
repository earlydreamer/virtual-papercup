# 저장소 감사 기록

2026-11-11에 첫 커밋 전의 로컬 파일을 기준으로 문서·정책·반입 경로를 점검했습니다. 원격 저장소의 과거 이력, 보호 규칙, 배포 환경은 이번 확인 범위에 포함하지 않았습니다.

## 확인한 문제와 조치

| 확인한 내용 | 반영한 조치 |
| --- | --- |
| README가 비어 있고 개발 규칙이 존재하지 않는 AGENTS.md를 참조했습니다. | 사용자용 README와 짧은 에이전트 진입점을 작성하고 개발·보안·기술 문서를 분리했습니다. |
| 반입 금지가 문장과 일부 ignore 규칙에만 의존했습니다. | 공개 파일 영역 검사, 비밀·내부 주소 패턴 검사, 링크·submodule 차단과 인덱스 원문 검사를 추가했습니다. |
| 기본 개발 서버가 모든 인터페이스에 바인딩했습니다. | 기본 바인딩을 localhost로 제한하고 다른 기기의 접속은 로컬 설정으로 명시하도록 변경했습니다. |
| `.env.local` 사용 안내와 `process.env`만 읽는 설정이 어긋났습니다. | `loadEnv`로 `PCUP_` 값을 읽고 환경 예시를 공개 가능한 기본값으로 제한했습니다. |
| 허용 호스트 설명이 HTTPS에서도 항상 접근을 차단하는 것처럼 읽혔습니다. | Vite 공식 문서와 대조해 HTTPS·IP 허용 예외, 별도 접근 제어의 필요성을 설명했습니다. |
| `npm test`가 기존 테스트 파일 세 개 중 하나만 실행했습니다. | 모든 테스트 파일을 실행하도록 수정했습니다. |
| 개발용 URL 쿼리로 배포판에서도 자동 시작과 샘플 결과 표시가 가능했습니다. | 개발 모드로 제한하고 빌드 결과에서 해당 입력과 화면 경로가 제외되는지 확인했습니다. |
| 기술 문서가 자세 보정·렌더링·수치 안정성을 구현보다 강하게 설명했습니다. | 실제 계산 경로, 테스트가 확인하는 조건, 아직 검증하지 않은 동작을 구분했습니다. |
| UI가 거치 각도와 법적 제한을 단정했습니다. | 기준 자세 보정 설명과 정차 후 사용 안내로 수정했습니다. |

공개 후보 파일에서 실제 인증정보·내부 주소·내부 자료 링크는 이번 점검으로 발견하지 못했습니다. 이 결과는 패턴 검사와 소스 검토 범위에 한정되며, 모든 비밀정보가 없다는 증명은 아닙니다. 기존 파일의 원본은 저장소 밖에 보관했고 외부 기록의 실제 경로·구조·메타데이터는 반입하지 않았습니다.

## 정책 선택

다른 프로젝트의 현재 규칙과 이전 문서 작성 결정을 대조해, 기존 변경 보존, 하나의 결과 단위로 작업하기, 한국어 커밋·PR, 단계별 검증 근거 구분을 반영했습니다. 커밋 형식은 소문자 conventional 타입과 한국어 설명으로 정했습니다.

README에는 사용자가 할 수 있는 일과 사용 순서, 필요한 제한을 둡니다. 개발 이력·내부 연결 구성·검증 보고는 분리합니다. 문체는 `ai-slop-thresher` 기준으로 정리하되 불확실성·조건·실패·미검증 정보를 보존합니다.

특정 모델·설치 경로·하네스·리뷰 서비스·보드 식별자, 다른 제품의 서버·프로필 정책은 가져오지 않았습니다. 이 저장소에서 재현할 수 있는 실행 명령과 검증 도구만 개발 기준으로 둡니다.

## 검증과 제한

- 기존 물리·자세 테스트 36개와 추가 방어·설정 테스트 15개를 포함해 51개 테스트가 통과했습니다. 신규 검사는 저장소 밖의 임시 폴더와 합성 데이터로 수행했습니다.
- 작업 트리 검사, TypeScript 검사, 프로덕션 빌드와 산출물 검사가 통과했습니다. 빌드 결과에서 URL 쿼리 입력·자동 시작·샘플 결과 경로가 제외되는지 확인했습니다.
- 공개 후보 32개 파일을 별도 임시 인덱스에 넣어 인덱스 원문 검사와 `git diff --cached --check`를 통과했습니다. 원래 인덱스는 비어 있는 상태로 보존했습니다. 문서 7개와 상대 링크 14개를 확인했습니다.
- 로컬 개발 서버의 루프백 바인딩, 앱·소스 응답, Git·개발 문서 접근 차단과 HTTP 미승인 호스트 거부를 확인했습니다. HTTPS의 호스트 검사는 Vite의 예외를 따릅니다.
- `npm audit` 조회에서 보고된 취약점은 0건이었습니다. 의존성 버전은 변경하지 않았습니다.
- CI 파일은 읽기 권한과 고정된 Action 커밋을 사용하며 Windows·Linux 검사를 정의했습니다. 원격 CI 실행과 저장소 보호 설정의 활성화는 확인하지 않았습니다.

실기기 센서·소리·진동·잠금 후 복귀와 운전 상황은 확인하지 않았습니다. 센서 미도착, 안정도와 기준 완료 조건, 측정 중 수위 조작 등 남은 제한은 [기술 문서](TECHNICAL.md)에 있습니다. 반입 검사는 과거 Git 이력을 검사하지 않으며, 자동 커밋 hook이나 원격 push 차단도 설치하지 않았습니다.
