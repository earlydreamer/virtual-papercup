# 개발 안내

Node.js 24와 npm을 사용합니다. 의존성은 `package-lock.json`에 맞춰 설치합니다.

```text
node scripts/check-repo.mjs
npm ci
npm run dev
```

기본 개발 서버는 자체 서명 인증서를 사용하는 로컬 HTTPS로 실행됩니다. 모바일 센서와 권한 처리는 실제 기기에서 확인합니다.

## 로컬 설정

설정이 필요할 때만 `.env.example`을 `.env.local`로 복사합니다. Vite 설정은 `PCUP_` 접두어의 값을 명시적으로 읽으며 같은 이름의 프로세스 환경 변수가 파일보다 우선합니다.

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PCUP_HOST` | `localhost` | 개발·미리보기 바인딩 주소. 다른 기기 접속이 필요할 때만 로컬에서 변경합니다. |
| `PCUP_PLAIN` | `0` | `1`이면 개발용 HTTPS를 끕니다. HTTPS를 제공하는 별도 개발 환경에서만 사용합니다. |
| `PCUP_ALLOWED_HOSTS` | 빈 값 | 직접 관리하는 호스트 이름을 쉼표로 구분합니다. URL·와일드카드·선행 점을 사용하지 않습니다. |

실제 장비나 네트워크 값은 커밋하지 않습니다. Vite의 [환경 변수 로딩](https://vite.dev/config/#using-environment-variables-in-config)과 [서버 옵션](https://vite.dev/config/server-options)에 따르면 `.env` 값은 설정 평가 전에 자동으로 `process.env`에 들어오지 않습니다. 또한 HTTPS에서는 허용 호스트 검사가 생략되며, IP 주소는 기본 허용 대상입니다. 호스트 목록을 접근 인증으로 취급하지 않습니다.

## 검사

| 명령 | 확인하는 범위 |
| --- | --- |
| `npm run check:repo` | 작업 트리의 공개 후보 파일, 링크, 전체 인덱스 |
| `npm run check:staged` | 전체 인덱스의 실제 내용과 파일 모드 |
| `npm test` | 모든 테스트 파일의 물리·자세 계산과 저장소 방어 규칙 |
| `npm run build` | 저장소 검사, `src/` 타입 검사, 프로덕션 빌드, 산출물 검사 |
| `npm run check:dist` | 기존 `dist/`의 링크·텍스트·민감정보 패턴 |
| `npm run preview` | 빌드 결과의 로컬 미리보기 |

테스트 개수는 실행 결과를 기준으로 합니다. 단위 테스트 통과가 센서 권한·소리·진동·실기기 동작의 통과를 뜻하지 않습니다. 문서 변경은 링크·명령·실제 동작과의 일치 및 공개 경계를 확인합니다.

빌드가 생성하는 `dist/`는 Git에서 제외합니다. 배포 전에는 새로 빌드한 산출물을 확인하고, 배포 권한이 있는 경우에만 전달합니다. CI 정의는 `.github/workflows/ci.yml`에 있으며 원격에서 실행되었는지는 별도로 확인해야 합니다.

## UI 확인용 입력

개발 서버에서는 `card`, `auto`, `tx`, `ty`, `flip`, `warm`, `keep` 쿼리로 화면과 합성 기울기를 확인할 수 있습니다. 예를 들어 `?auto=1&tx=0.5&ty=0`은 자동 시작 후 고정 기울기를 적용합니다. `?auto=1&tx=0&ty=0.9&keep=1`은 물 높이를 유지하며 앞쪽으로 넘치는 모습을 표시합니다. 이 입력은 프로덕션 빌드에서 사용하지 않습니다. 합성 입력 확인을 실제 센서 검증으로 보고하지 않습니다.

3D 의존성의 UUID 배열을 압축기가 점으로 연결된 문자열로 변환하면 산출물 검사에서 사설 주소로 오인할 수 있습니다. 빌드는 배열 구조를 유지하고 이름·공백을 축소하도록 설정합니다. 산출물의 주소 검사 규칙은 그대로 적용합니다.

## 실기기에서 확인할 항목

정지 상태에서 센서 권한 허용·거부, 실제 샘플 도착, 기준 설정과 재설정, 넘침 소리·진동, 종료·재시작을 확인합니다. 화면 회전, 센서 중단, 탭 전환·잠금 후 복귀는 별도 항목으로 기록합니다. 검증 기록에는 공개 가능한 OS·브라우저 버전과 관찰 결과만 남기고 기기 식별자·주소·개인 화면은 제외합니다.
